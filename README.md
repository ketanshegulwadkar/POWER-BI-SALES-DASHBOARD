# 📊 Sales Data Analysis Dashboard (Power BI)

## 📌 Project Overview

This project focuses on analyzing sales data using Power BI to uncover meaningful business insights. The dashboard provides a clear and interactive view of sales performance across different regions, categories, and time periods.

---

## 🎯 Objective

The main objective of this project is to:

* Analyze overall sales performance
* Identify top-performing regions and product categories
* Track monthly sales trends
* Enable data-driven decision-making through visualization

---

## 🛠️ Tools & Technologies Used

* **Power BI** (Data Visualization & Dashboard Creation)
* **Excel / CSV Dataset** (Data Source)

---

## 📂 Dataset

The dataset used in this project contains:

* Order Date
* Sales
* Region
* Category
* Customer Details

*(Dataset sourced from publicly available sales data - Superstore dataset)*

---

## ⚙️ Steps Performed

### 1. Data Loading

* Imported dataset into Power BI using **Get Data (CSV)**

### 2. Data Cleaning

* Removed null values
* Corrected data types (Date, Numeric fields)

### 3. Data Transformation

* Structured dataset for better analysis
* Ensured consistency across columns

### 4. Data Visualization

Created interactive dashboard using:

* KPI Card (Total Sales)
* Bar Chart (Sales by Region)
* Pie Chart (Sales by Category)
* Line Chart (Monthly Sales Trend)

### 5. Filters / Slicers

* Region filter
* Category filter

---

## 📊 Key Features

* Interactive dashboard for dynamic filtering
* Clear visualization of business KPIs
* Easy-to-understand charts for decision-making
